# Easy Task

Easy Task is a simple task manager application built with Angular **18.2.14**.
The project was created to learn and practice core Angular concepts.

## Features

* Add tasks
* Remove tasks
* Display tasks based on a selected user (clicked)
* Persistent storage using browser LocalStorage

## Technologies

* Angular 18.2.14
* TypeScript
* HTML & CSS
* Browser LocalStorage API

## Purpose

This application was developed as a learning project to better understand Angular fundamentals such as components, templates, directives, services, data binding, event handling, user input and state management.

## How It Works

Users can create and manage tasks in a simple interface.
Tasks are associated with users, and selecting a user will display their respective tasks.
All data is stored locally in the browser using LocalStorage, so tasks persist even after refreshing the page.

## Getting Started

1. Clone the repository
2. Install dependencies

   ```bash
   npm install
   ```
3. Run the application

   ```bash
   ng serve
   ```
4. Open your browser at

   ```
   http://localhost:4200
   ```

## Notes

This is a basic project focused on learning and does not include advanced features like authentication or backend integration.
